## Usage

1. Download [vague.itermcolors](vague.itermcolors).

2. In iTerm2, open **Settings** > **Profiles** > **Colors**.

3. Open the **Color Presets…** menu, choose **Import…**, and select the downloaded file.

4. Select `vague` from the **Color Presets…** menu.
